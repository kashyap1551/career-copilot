# The ten invented ads for the 10-ad manual check (P0)

For the owner. Used by `docs/MANUAL-CHECK-7.1.md` step 10 and by `docs/MANUAL-CHECK-7.3.md`. Invented material only: no real person, company or ad.

Each ad asks for SQL and nothing else (no nice-to-have, no years of experience, no language, no start date). Each is in Berlin and hybrid, like the ads of step 3 of `docs/MANUAL-CHECK-7.1.md`, so none clashes with the profile used there (the city `Berlin`).

Paste the ads **one at a time**: **Read this ad**, then **Save this ad**. The free tier allows about one large read a minute, so wait about a minute between reads. Each ad text is different (a saved ad is kept under a key made from its text, so two equal texts would become one saved ad).
